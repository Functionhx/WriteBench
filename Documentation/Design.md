# WriteBench 1.1 design

The supplied screenshot grounded 1.0. The user's subsequent instruction makes a quiet, mandatory answering workspace the priority for 1.1.

Preparation: 200-point white sidebar, simple exam selector, an 820-point maximum content column with question and one Start button. No companion rail, landscape decoration, greeting card, profile avatar or editable essay.

Answering: automatic native full screen. White surface, restrained 62-point command strip, native split divider between readable question and the answer surface. No sidebar, exam tabs, settings shortcut, formatting toolbar, gradients, decorative cards or optional focus switch. Save-and-leave preserves the draft; Start is required to re-enter.

Paper exams use a native ruled NSTextView with a serif writing font and fixed line spacing. No live word count for Kaoyan or CET-6. IELTS uses a simple unruled editor with a small count. Blue is reserved mainly for the Hand in button. Standard Mac selection/undo/copy/paste remain native.

All rewriting routes return to the same answering workspace. OCR correction is still a separate, necessary source-verification step; it is never automatically graded.
