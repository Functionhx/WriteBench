# Kaoyan English II — large essay
Version: 2026.10-v1
Scale: 0–15, half-point estimates. Typical length: about 150 words. App-owned practice rubric, not official examiner guidance.
English II large essays are usually based on a chart or table. Assess: accurate description of the key data and its overall trend or comparison, using the figures actually given; a reasonable interpretation of causes or meaning; relevant comments; coherent paragraphs; language range and accuracy. Selecting the main features matters more than listing every number. Misreading or inventing data is a task-completion error. Rely only on the figure transcription in the question; never invent unseen values.
Anchors: 13–15 complete, accurate data description with developed, relevant comment and varied accurate language; 10–12 generally complete and coherent despite some errors or thin development; 7–9 basic relevant response with weak data use or noticeable errors; 4–6 significant omissions, misread data or language problems; 1–3 minimal relevant communication; 0 blank or wholly unrelated.
Avoid rigid template rewards. Report overall score on 15, and diagnostics on 10.
